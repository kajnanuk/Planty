## Opis
Aplikacja Planty służy do zarządzania domowym ogrodem. Użytkownik po zalogowaniu może dodać rośliny do swojego ogrodu, przeglądać ich właściwości i potrzeby. Aplikacja podpowiada użytkownikowi kiedy należy podlać jego rośliny, sprawdza zrównoważenie warstwowe ogrodu oraz pilnuje aby w ogrodzie użytkownika nie wystąpiła alleopatia - negatywne reakcje pomiędzy niektórymi gatunkami. 

Aplikacja udostępnia również ciekawe statystyki o zarejestrowanych roślinach, które są dostępne także dla niezalogowanych użytkowników.

Nowe gatunki roślin które użytkownik może potem dodać do swojego ogrodu rejestruje się łatwo z poziomu aplikacji. 

W aplikacji można przeglądać encyklopedię zarejestrowanych roślin, ich wymagań i potrzeb oraz relacji z innymi gatunkami.
